# ChatGPT 무료 샘플 프롬프트 6선

> 1인 사업자·직장인을 위한 **바로 복사해 쓰는** 한국어 프롬프트 샘플입니다.
> 전체 팩(SNS30 / PROMPT80 / PROMPT80PLUS)은 스토어에서 구매할 수 있습니다.
>
> 스토어: https://macmini-jarvis.github.io/chatgpt-prompts-pack-store/
> 성장 허브: https://macmini-jarvis.github.io/prompt-growth-hub/

## 사용 방법

1. 아래 프롬프트를 복사합니다.
2. `{중괄호}` 값을 본인 업종·타깃·톤으로 바꿉니다.
3. ChatGPT(또는 동일 계열 AI)에 붙여넣고 실행합니다.
4. **사실·정책·수치·개인정보는 반드시 검수**한 뒤 사용합니다.

## 면책

본 자료는 업무 속도를 돕는 도구이며 노출·매출·수익을 보장하지 않습니다.
무단 재배포·재판매를 금지합니다. 샘플은 공개 배포용이며, 유료 풀팩과 구성이 다릅니다.

## 1. 인스타 피드 캡션 3안 (샘플)

**언제:** 제품·서비스 소개 피드를 빠르게 써야 할 때

```
당신은 한국 인스타그램 카피라이터입니다.
아래 정보로 피드 캡션 3안을 작성하세요.

[업종]: {업종}
[제품/서비스]: {제품명}
[핵심 혜택]: {핵심혜택}
[타깃]: {타깃}
[톤]: {톤}  (친근함 / 전문적 / 감성)

조건:
- 각 캡션 80~140자
- 첫 줄에 스크롤을 멈추는 훅 1문장
- CTA 한 줄 (프로필 링크 또는 DM)
- 해시태그 8개 별도 제안
- 과장·허위 표현 금지
```

## 2. 릴스 훅 문구 8개 (샘플)

**언제:** 릴스 첫 3초 오프닝이 필요할 때

```
인스타 릴스용 훅(첫 문장) 8개를 만들어 주세요.

[주제]: {주제}
[타깃]: {타깃}
[목표]: {목표}  (저장 / 공유 / 프로필 방문)

형식:
- 번호 + 훅 (15자 내외)
- 옆에 '왜 효과적인지' 한 줄
- 구어체, 광고 과장 금지
```

## 3. 상세페이지 헤드라인 + 서브카피 (샘플)

**언제:** 상품 상세 상단 카피가 막힐 때

```
당신은 이커머스 카피라이터입니다.
상세페이지 상단용 헤드라인 5안과 서브카피 5안을 작성하세요.

[상품명]: {상품명}
[핵심 혜택]: {혜택}
[타깃 고민]: {고민}
[차별점]: {차별점}
[톤]: {톤}

조건:
- 헤드라인 18~28자
- 서브카피 40~70자
- 혜택 중심, 허위 할인·효과 보장 문구 금지
- 각 안 옆에 '어떤 고객에게 맞는지' 한 줄
```

## 4. 블로그 SEO 글 목차 + 서론 (샘플)

**언제:** 검색 유입용 글의 뼈대를 잡을 때

```
한국어 블로그 SEO 글의 목차와 서론을 작성하세요.

[주제 키워드]: {키워드}
[검색 의도]: {의도}  (정보 / 비교 / 구매 검토)
[타깃]: {타깃}
[글 목표]: {목표}

출력:
1) H2/H3 목차 6~8개
2) 서론 150~220자 (키워드 자연 삽입 1회)
3) 각 H2에 넣을 '핵심 포인트' 한 줄
4) 메타 디스크립션 초안 120자 이내
```

## 5. 긍정 리뷰 답글 템플릿 (샘플)

**언제:** 좋은 리뷰에 빠르게·일관되게 답할 때

```
온라인 스토어 긍정 리뷰 답글 5안을 작성하세요.

[업종]: {업종}
[상품/서비스]: {상품}
[리뷰 요약]: {고객이 칭찬한 점}
[브랜드 톤]: {톤}
[다음 행동 유도]: {CTA}  (예: 재구매 쿠폰 안내 / 스토리 태그 요청 — 실제 정책만)

조건:
- 각 답글 2~4문장
- 고객 이름을 넣지 않음 (개인정보 최소화)
- 과장 감사·허위 혜택 금지
- 해요체
```

## 6. 업무 메일 초안 (샘플)

**언제:** 정중하지만 짧은 업무 메일이 필요할 때

```
한국어 업무 메일 초안을 작성하세요.

[목적]: {목적}  (예: 일정 조율 / 견적 요청 / 회신 독촉)
[수신자 관계]: {관계}  (상사 / 거래처 / 동료)
[핵심 내용]: {내용}
[원하는 다음 행동]: {요청}
[톤]: 정중·간결

출력:
- 제목 3안
- 본문 1안 (200자 내외)
- 더 짧게 / 더 부드럽게 변형 각 1안
```
