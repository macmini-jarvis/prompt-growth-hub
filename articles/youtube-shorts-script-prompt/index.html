유튜브 쇼츠 훅·대본·제목, ChatGPT로 짜는 실전 가이드

유튜브 쇼츠는 인스타 릴스와 비슷해 보이지만, 승부 지점이 다릅니다. 릴스는 피드 캡션 첫 줄과 탐색 탭 감성이 크고, 쇼츠는 제목·첫 1~3초 화면·중간 리텐션 비트·루프 가능한 엔딩이 한 세트로 움직입니다. ChatGPT에게 ‘쇼츠 대본 써줘’만 시키면 광고 카피처럼 과장되고, 초 단위 호흡이 빠집니다. 이 글은 제목 → 훅 → 챕터형 대본 → CTA 순으로 쪼개 쓰는 방법입니다.

조회수·구독·수익을 약속하는 문구는 쓰지 마세요. 통제할 수 있는 것은 문장 구조, 비트 간격, 화면 텍스트, 검수뿐입니다. AI 초안은 반드시 소리 내어 읽고, 사실·정책·브랜드 톤을 고친 뒤에만 촬영하세요.

1. 릴스와 쇼츠를 이렇게 구분하세요

  • 제목: 쇼츠는 검색·추천·관련 영상에 제목이 그대로 노출됩니다. 캡션이 아니라 짧은 검색어형 제목이 필요합니다.
  • 훅 1~3초: 말하는 문장 + 화면 큰 글자 + 첫 컷의 움직임이 동시에 맞아야 합니다.
  • 리텐션 비트: 3~7초마다 정보·반전·화면 전환이 있어야 스와이프가 줄어듭니다. 한 호흡 나열은 중반에서 끊깁니다.
  • CTA: 저장·프로필보다 ‘다음 숏 연결, 고정댓글, 관련 영상, 구독 이유 한 줄’이 자연스럽습니다.
  • 루프: 마지막 컷이 첫 훅과 이어지면 반복 시청이 생깁니다. 억지 반전보다 질문으로 닫는 편이 안전합니다.

인스타 캡션·해시태그 중심 작업이 필요하면 인스타 캡션·릴스 훅 가이드를 보세요. 쇼츠는 그 글을 복사하지 말고, 아래처럼 타임코드가 있는 챕터 대본으로 다시 짜세요.

2. 쇼츠 제목: 검색어 + 약속, 한 줄

한국어 쇼츠 제목은 보통 18~40자가 읽기 좋습니다. 핵심 키워드를 앞에 두고, 뒤에 구체 상황이나 결과 약속을 붙입니다. 예: ‘쇼츠 대본 프롬프트 | 첫 3초만 고치는 법’. ‘대박’, ‘무조건’, ‘1만 조회 보장’ 같은 표현은 빼세요. 숫자는 실제로 있는 시간·개수·단계만 넣습니다.

  • 검색형: 사람들이 입력할 법한 명사(쇼츠 대본, 훅, 제목)를 앞에
  • 상황형: 타깃이 자기 일로 느끼게(1인 사업, 강의, 제품 소개)
  • 구조형: ‘3비트’, ‘15초’, ‘챕터 4컷’처럼 형식만 약속

제목과 화면 첫 글자가 완전히 같으면 중복 느낌이 납니다. 제목은 검색, 화면 텍스트는 스크롤 중 시선 차단용으로 역할을 나누세요.

3. 예시 프롬프트 — 쇼츠 제목 8안

당신은 한국 유튜브 쇼츠 제목만 담당하는 에디터입니다. 조회수·수익을 장담하지 말고, 검색·추천용 제목 초안만 만드세요. [주제]: {주제} [타깃]: {타깃} [핵심 키워드]: {키워드 2~3개} [길이]: 15~40초 [톤]: 구어체, 과장 금지 출력: - 제목 8안 (18~40자) - 각 안: 앞부분 키워드 / 뒤에 붙인 약속 / 맞는 상황 한 줄 금지: 조회 보장, 월 매출, 허위 수치, 의료·금융 단정

4. 첫 1~3초 훅: 말·글·움직임

훅은 ‘흥미로운 문장’이 아니라 스와이프를 멈추는 한 컷입니다. 1초에 화면 큰 글자가 뜨고, 동시에 입으로 질문을 던지고, 손이 물건을 집어 들거나 텍스트가 바뀌면 정보가 겹칩니다. 문장만 길고 화면이 정지하면 훅이 아닙니다.

  1. 손실·실수형: “첫 3초를 인사로 시작하면 여기서 나갑니다”
  2. 과정 공개형: “이 15초 대본, 비트 네 개로만 씁니다”
  3. 반전 전제형: “캡션 잘 써도 쇼츠에선 제목이 먼저입니다” → 바로 고치기
  4. 체크리스트형: “촬영 전에 제목·훅·CTA만 확인하세요”

15자 안팎의 화면 텍스트와, 그보다 조금 긴 구어체 대사를 따로 받으세요. 한 문장을 둘 다에 쓰면 읽기와 듣기가 충돌합니다. 소리 내어 읽었을 때 숨이 차면 잘라 주세요.

5. 챕터형 대본: 리텐션 비트를 시간으로 고정

쇼츠 대본은 에세이가 아닙니다. 챕터(비트)로 자르면 촬영 메모와 화면 자막이 같이 나옵니다. 15~35초 기준으로 아래 뼈대를 쓰면 ChatGPT 편차가 줄어듭니다.

  1. 0:00–0:03 훅 — 질문 또는 실수 지적. 화면 텍스트 1줄.
  2. 0:03–0:08 문제 — 타깃이 겪는 구체 상황. 추상어(혁신, 최고) 금지.
  3. 0:08–0:20 비트 2~3개 — 각 비트마다 한 가지 정보 + 화면 전환 힌트.
  4. 0:20–0:28 CTA — 한 가지 행동만. 구독 이유 또는 다음 숏 예고.
  5. 0:28–끝 루프 씨앗 — 첫 훅과 이어지는 짧은 질문.

비트마다 ‘지금 화면에서 무엇이 바뀌는가’를 적지 않으면, 나레이션만 긴 슬라이드가 됩니다. 제품 쇼츠라면 비트와 상품 컷을 맞추고, 강의형이면 숫자·목록이 화면에 떠야 합니다. 상세페이지처럼 혜택을 길게 설득해야 한다면 상세페이지 카피 가이드에서 메시지를 먼저 고정한 뒤, 쇼츠용으로 한 혜택만 가져오세요.

6. 예시 프롬프트 — 챕터형 대본 + 리텐션 비트

한국 유튜브 쇼츠용 챕터형 대본을 작성하세요. 인스타 캡션이 아니라, 초 단위 비트와 화면 지시를 포함하세요. [주제]: {주제} [타깃]: {타깃} [핵심 메시지 1개]: {메시지} [길이]: 20~30초 [출연]: {얼굴 / 손만 / 화면텍스트 중심} [톤]: 해요체 구어, 광고 과장 금지 출력 형식: 1) 제목 3안 2) 챕터 표 - 타임코드 - 대사 (한 호흡) - 화면 텍스트 (12~18자) - 화면에서 바꿀 것 (컷/제스처/줌) 3) 훅(0~3초)만 따로 5안 4) 엔딩 CTA 1개 + 루프용 마지막 문장 1개 금지: 조회·수익 보장, 허위 후기, 없는 수치, 개인정보

7. CTA와 설명란: 한 행동만

쇼츠 끝에서 ‘좋아요, 구독, 알림, 댓글, 공유’를 한 번에 시키면 행동이 사라집니다. CTA는 하나가 원칙입니다. 정보형이면 고정댓글에 체크리스트를 두고 ‘댓글 키워드’만 말하게 하세요. 제품 소개면 상세 링크보다 먼저, 지금 화면에서 확인한 혜택 한 줄을 반복합니다. 설명란은 제목의 검색어를 한 번 더 쓰고, 촬영에 없는 효과를 지어내지 마세요.

  • 정보형 CTA: “다음 숏에서 ○○만 이어서 보여 드립니다”
  • 저장 대체: 유튜브는 재생목록·나중에 보기가 약하므로, 화면 텍스트로 핵심 3개를 다시 띄우기
  • 구독 CTA: ‘구독하세요’보다 ‘이 주제로 숏을 이어갑니다’처럼 이유

8. 예시 프롬프트 — 훅·CTA·설명란 다듬기

아래 쇼츠 초안을 리텐션 기준으로 다듬어 주세요. [초안 대본]: {붙여넣기} 작업: - 0~3초 훅을 더 짧게, 화면 텍스트와 대사를 분리 - 중반을 3~7초 비트로 재분할 (비트마다 화면 전환 힌트) - CTA는 1개만 남기고 나머지는 삭제 - 설명란 80~140자 + 해시태그 5개 (주제와 직접 관련된 것만) - 추상어·보장 표현 삭제, 사실 없으면 [확인필요] 출력: 수정 대본 / 변경 이유 3줄 / 촬영 체크 질문 5개

9. 촬영 전 체크리스트

  • 제목 앞 10자에 핵심 키워드가 보이는가?
  • 0~3초에 화면 글자·대사·움직임이 겹치는가?
  • 중반 비트마다 정보가 하나씩만 들어오는가?
  • CTA가 두 개 이상이지 않은가?
  • 마지막 문장이 첫 훅과 이어져 루프가 가능한가?
  • 숫자·후기·인증을 모델이 지어내지 않았는가?
  • 브랜드 말투와 다른 AI 번역체(‘혁신적인 솔루션’ 등)가 없는가?
  • 의료·금융·법률 단정이 섞이지 않았는가?

체크리스트를 통과해도 성과는 보장되지 않습니다. 다만 같은 주제를 세 번 찍을 때 제목만 바꾸기, 훅만 바꾸기, 비트 순서만 바꾸기처럼 변인을 하나만 두면 무엇이 어색했는지 판단하기 쉽습니다.

10. 자주 하는 실수

첫 번째는 릴스 캡션을 그대로 쇼츠 제목으로 쓰는 것입니다. 이모지와 해시태그가 쇼츠 제목을 지저분하게 만듭니다. 두 번째는 인사말로 3초를 쓰는 것입니다. 세 번째는 한 프롬프트에 제목·대본·커뮤니티 글·상세 카피까지 몰아넣는 것입니다. 작업 단위를 나누세요. 네 번째는 비트 없이 설명만 길게 읽는 것입니다. 다섯 번째는 검수 없이 화면 자막까지 자동 생성에 맡기는 것입니다. 자동 자막은 고유명사와 숫자에서 자주 틀립니다.

실무에서는 주간으로 ‘이번 주 쇼츠 한 주제’를 정하고, 제목 8안 → 훅 5안 → 챕터 대본 1안 순으로 고정하는 편이 안정적입니다. 마음에 드는 톤이 나오면 ‘위 비트 간격 유지’라고만 이어 가세요. 프롬프트 기본 구성(역할·입력값·출력 형식·제약)이 헷갈리면 프롬프트 추천·쓰는 법을 먼저 보세요.

11. 상품·강의 쇼츠로 확장할 때

제품 한 개를 보여 줄 때는 상세페이지의 혜택 전체를 넣지 마세요. 혜택 하나 + 사용 장면 하나 + FAQ 한 줄이면 30초 안에 끝납니다. 가격·환불·배송은 사실이 확인된 문장만 쓰고, 모르면 화면에서 빼 두세요. 강의·코칭형은 ‘오늘 연습 한 가지’만 남기는 것이 챕터 구조와 잘 맞습니다.

더 많은 한국어 실전 프롬프트가 필요하면 허브 무료 샘플로 톤을 시험한 뒤, 스토어 팩으로 확장하면 됩니다. 샘플과 유료 팩 모두 초안용이며 발행 전 검수는 사용자 몫입니다.
